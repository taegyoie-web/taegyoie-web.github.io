# BM Portfolio — GitHub Pages

## Upload
1. Open https://github.com/taegyoie-web/taegyoie-web.github.io
2. Choose **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js` at the repository root (not the ZIP).
3. Commit changes.
4. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)** and Save.
5. Visit https://taegyoie-web.github.io after deployment.

## Before sharing with recruiters
- This is a first draft with concept-only graphics, not actual product photographs.
- Review all project descriptions and dates for accuracy.
- Do not upload confidential manufacturing data, unreleased packaging, internal test reports, or supplier pricing without approval.
- Replace placeholder visual graphics with approved public imagery.
- Add a verified contact method and resume link if desired.
